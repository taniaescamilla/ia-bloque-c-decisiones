Conceptos JSON demostrados

Tipos de datos JSON

String, Number, Boolean, null, Array, Object. Todos visibles en las respuestas de la API (tag_list es array, user es objeto anidado, comments_count es number).

REST API + CRUD

GET = Read, POST = Create, PUT = Update, DELETE = Delete. Los 4 metodos HTTP mapeados a operaciones sobre recursos JSON.

Query Parameters vs Path Parameters

?tag=ai&per_page=5 (query) filtra la coleccion. /articles/4559844 (path) identifica un recurso especifico.

JSON Schema

Esquema de validacion que define la estructura esperada: tipos, campos requeridos, patrones de URL, enumeraciones (ai_disclosure_level). Draft 2020-12.

Objetos anidados

El campo "user" dentro de cada articulo es un objeto con sus propias propiedades (name, username, github_username). JSON permite anidamiento arbitrario.

Conexion con NoSQL (MongoDB)

Cada articulo JSON se inserta directamente como documento en MongoDB sin transformacion. Los arrays (tag_list) y objetos anidados (user) se almacenan tal cual, a diferencia de SQL donde requeririan tablas separadas.
